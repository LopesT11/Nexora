DEALER$ — ATUALIZAÇÃO
========================
Versão: 28.0.0

Ficheiros incluídos:
- index.html
- style.css
- app.js
- manifest.json
- sw.js
- icon-192.png
- icon-512.png

Instalação:
1. Extrair tudo.
2. Substituir os ficheiros existentes no repositório pela versão desta pasta.
3. Fazer commit/push para o GitHub Pages.
4. Se o telemóvel mostrar a versão antiga, fechar a PWA e atualizar a página uma vez para renovar o Service Worker.

Alterações principais desta versão:
- Dashboard reorganizado segundo o layout confirmado.
- Estados Recebido / Já gasto / A reservar / Devolvido / Disponível.
- Reservas com Criar, Editar, Retirar, Transferir, Confirmar e Cancelar.
- Transferência de reserva para Poupança, Dinheiro a render, Fundo carro, Seguro, Exterior ou Conta corrente.
- Despesas por pagar permanecem informativas até serem pagas.
- Ao pagar uma despesa, escolhe-se valor, data e origem do dinheiro.
- Receita manual permite escolher mês atual, próximo mês ou automático pelas regras de ordenado/bónus.
- Tema claro/escuro.
- Service Worker atualizado para limpar a cache anterior.


Esta versão lê os dados existentes em `dealers_data_v2` para não abrir a app vazia nem apagar os dados da versão anterior.
